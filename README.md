This is the latest version of our malaria in pregnancy model, used in our current preprint [LINK TO PREPRINT].

The version associated with our published article,  
["Modelling the incremental benefit of introducing malaria screening strategies to antenatal care in Africa"](https://www.nature.com/articles/s41467-020-17528-3),  
is archived [here as release v1.0-istp_paper](https://github.com/patrickgtwalker/malaria_in_pregnancy_istp_model_open/releases/tag/v1.0-istp_paper).

To run the current version, please clone the repository and follow the steps in [INSTRUCTIONS.md](INSTRUCTIONS.md).
For detailed background or the original formatting, `Instructions.docx` is still included, but the essentials are summarised in the Markdown file for convenience.
